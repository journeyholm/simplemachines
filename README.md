# Ogg & Ugg's Machine Lab

A 3D simple machines game for **The 500 lb Prehistoric Problem**: build levers, ramps, wedges, wheels & axles, pulleys, and screws from sticks, stones, and vines, then use them to get a 500 lb boar home.

- **Free preview:** open the site and choose *Try the free preview* (Lever and Ramp).
- **Full game:** enter the password from the teacher guide. Each device remembers it.
- **Lock a shared device again:** add `?lock` to the end of the address.

The full game is stored encrypted (`game.bin`); it cannot be opened without the password.
